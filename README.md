## Commands

List of customized commands

### Bash

```
la
```
List all (including hidden) as list (ls -al)

---

```
ls
```
List as list (ls -l)

--- 

```
conf
```
Open .bashrc configuration file in text editor

---

### Git

```
git st
```
Show git status -sb

---

```
git sta
```
Show git status

---

```
git conf
```
Edit config file git config --global --edit

---

```
git pr
```
Pull with rebase git pull --rebase

---

```
git br
```
Display local branches git branch

---

```
git bra
```
Display all branches git branch -a

---

```
git ci
```
Git commit

---

```
git ciam
```
Git commit -a --amend

---

```
git co
```
Git checkout

---

```
git aa
```
Git add everything git add -A

---
